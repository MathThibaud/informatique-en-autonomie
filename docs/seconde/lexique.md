# Lexique

*Les définitions sont résumées ; le renvoi (chapitre et page, cliquable) mène à la définition complète dans le cours.*

### A

**Actionneur** — Organe qui agit sur le monde physique (sortie) : moteur, lampe, haut-parleur…*(ch. 8, [voir le cours](08-informatique-embarquee-et-objets-connect/cours.md#lex-actionneur08))*

**Adresse IP** — Numéro d’une machine sur le réseau ; en IPv4, quatre nombres de 0 à 255 (IPv6 : adresses bien plus longues). *(ch. 6, [voir le cours](06-internet/cours.md#lex-ip06))*

**Affectation** — Instruction qui donne une valeur à une variable ; en Python, le signe `=`. *(ch. 1, [voir le cours](01-les-bases-de-la-programmation-python/cours.md#lex-affectation01))*

**Algorithme de recommandation** — Programme qui choisit et ordonne les contenus affichés dans votre fil, d’après ce que vous avez déjà regardé ou aimé. *(ch. 2, [voir le cours](02-les-reseaux-sociaux/cours.md#lex-recommandation02))*

### B

**Balise** — Marque HTML, ouvrante et fermante (`<p>`…`</p>`), qui délimite un élément de la page. *(ch. 4, [voir le cours](04-le-web/cours.md#lex-balise04))*

**Big data** — Données trop volumineuses pour les outils classiques : les « 3 V » (Volume, Vélocité, Variété). *(ch. 5, [voir le cours](05-les-donnees-structurees-et-leur-traiteme/cours.md#lex-bigdata05))*

**Booléen** — Valeur qui ne peut être que `True` (vrai) ou `False` (faux). *(ch. 1, [voir le cours](01-les-bases-de-la-programmation-python/cours.md#lex-booleen01))*

**Boucle** — Structure qui répète des instructions : `for` (nombre de répétitions connu) ou `while` (tant qu’une condition est vraie). *(ch. 1, [voir le cours](01-les-bases-de-la-programmation-python/cours.md#lex-boucle01))*

**Boucle de commande** — Programme qui répète sans fin : mesurer (capteur), décider, agir (actionneur). *(ch. 8, [voir le cours](08-informatique-embarquee-et-objets-connect/cours.md#lex-boucledecommande08))*

**Bulle de filtres** — Effet d’un algorithme de recommandation qui finit par ne plus montrer que ce qui vous plaît. *(ch. 2, [voir le cours](02-les-reseaux-sociaux/cours.md#lex-bulle02))*

### C

**Capteur (objet)** — Organe qui mesure une grandeur physique et la transforme en nombre (entrée). *(ch. 8, [voir le cours](08-informatique-embarquee-et-objets-connect/cours.md#lex-capteur08))*

**Capteur (photographique)** — Surface couverte de millions de photosites qui transforment la lumière reçue en nombres. *(ch. 3, [voir le cours](03-la-photographie-numerique/cours.md#lex-capteurphoto03))*

**Carte numérique** — Carte en couches d’informations sur laquelle on peut zoomer, mesurer et calculer un itinéraire. *(ch. 7, [voir le cours](07-localisation-cartographie-et-mobilite/cours.md#lex-carte07))*

**Chaîne de caractères** — Du texte, écrit entre guillemets (type `str`). *(ch. 1, [voir le cours](01-les-bases-de-la-programmation-python/cours.md#lex-chaine01))*

**Client, serveur** — Le client (le navigateur) demande une page ; le serveur, allumé en permanence, la stocke et la renvoie. *(ch. 4, [voir le cours](04-le-web/cours.md#lex-clientserveur04))*

**Compilateur, interpréteur** — Programmes qui traduisent en langage machine des instructions écrites avec des mots. Python est un langage interprété. *(ch. 1, [voir le cours](01-les-bases-de-la-programmation-python/cours.md#lex-compilateur01))*

**Concaténation** — Mise bout à bout de deux chaînes de caractères avec le signe `+`. *(ch. 1, [voir le cours](01-les-bases-de-la-programmation-python/cours.md#lex-concatenation01))*

**Cookie** — Petit fichier déposé par un site dans le navigateur pour vous reconnaître, ou vous suivre de site en site. *(ch. 4, [voir le cours](04-le-web/cours.md#lex-cookie04))*

**CSS** — Langage qui décrit l’apparence d’une page web (couleurs, polices, mise en page). *(ch. 4, [voir le cours](04-le-web/cours.md#lex-css04))*

**CSV** — Format texte ouvert pour les tables : une ligne par enregistrement, valeurs séparées par des virgules ou des points-virgules. *(ch. 5, [voir le cours](05-les-donnees-structurees-et-leur-traiteme/cours.md#lex-csv05))*

### D

**Définition (d’une image)** — Nombre de pixels d’une image : largeur $\times$ hauteur. *(ch. 3, [voir le cours](03-la-photographie-numerique/cours.md#lex-definition03))*

**Degré** — Nombre d’arêtes qui partent d’un sommet d’un graphe (le nombre d’amis). *(ch. 2, [voir le cours](02-les-reseaux-sociaux/cours.md#lex-degre02))*

**Descripteur, enregistrement** — Un descripteur est une colonne d’une table ; un enregistrement en est une ligne. *(ch. 5, [voir le cours](05-les-donnees-structurees-et-leur-traiteme/cours.md#lex-descripteur05))*

**Diamètre, rayon, centre** — Plus grande et plus petite excentricité d’un graphe ; le centre est le sommet dont l’excentricité est la plus petite. *(ch. 2, [voir le cours](02-les-reseaux-sociaux/cours.md#lex-diametre02))*

**Distance (graphe)** — Longueur (en nombre d’arêtes) de la plus courte chaîne qui relie deux sommets. *(ch. 2, [voir le cours](02-les-reseaux-sociaux/cours.md#lex-distance02))*

**DNS** — Annuaire d’Internet : il traduit une adresse symbolique (`google.fr`) en adresse IP. *(ch. 6, [voir le cours](06-internet/cours.md#lex-dns06))*

**Donnée** — Information élémentaire enregistrée : un nombre, un mot, une date, une image…*(ch. 5, [voir le cours](05-les-donnees-structurees-et-leur-traiteme/cours.md#lex-donnee05))*

**Donnée personnelle** — Donnée qui permet d’identifier une personne, directement ou indirectement. *(ch. 2, [voir le cours](02-les-reseaux-sociaux/cours.md#lex-donneeperso02) ; ch. 5, [voir le cours](05-les-donnees-structurees-et-leur-traiteme/cours.md#lex-donneeperso05))*

**Droit d’auteur, licence** — Le droit d’auteur protège toute création ; une licence fixe ce qu’on a le droit d’en faire. *(ch. 4, [voir le cours](04-le-web/cours.md#lex-droitauteur04))*

### E

**E-réputation** — Image que votre identité numérique donne de vous aux autres. *(ch. 2, [voir le cours](02-les-reseaux-sociaux/cours.md#lex-ereputation02))*

**Excentricité** — Distance d’un sommet au sommet le plus éloigné de lui. *(ch. 2, [voir le cours](02-les-reseaux-sociaux/cours.md#lex-excentricite02))*

### F

**Filtre de Bayer** — Mosaïque de petits filtres rouges, verts et bleus placée devant les photosites pour capter la couleur. *(ch. 3, [voir le cours](03-la-photographie-numerique/cours.md#lex-bayer03))*

**Fonction** — Mini-programme qui porte un nom, reçoit des valeurs d’entrée (les paramètres) et renvoie souvent un résultat (`return`). *(ch. 1, [voir le cours](01-les-bases-de-la-programmation-python/cours.md#lex-fonction01))*

**Format ouvert** — Format dont la structure est publique, lisible par n’importe quel logiciel ; s’oppose au format fermé (propriétaire). *(ch. 5, [voir le cours](05-les-donnees-structurees-et-leur-traiteme/cours.md#lex-formatouvert05))*

### G

**GPS, GNSS** — Système de positionnement par satellites (américain) ; GNSS désigne l’ensemble de ces systèmes (GPS, Galileo, GLONASS, BeiDou). *(ch. 7, [voir le cours](07-localisation-cartographie-et-mobilite/cours.md#lex-gps07))*

**Graphe** — Ensemble de sommets (les personnes) reliés par des arêtes (les relations) ; il modélise un réseau social. *(ch. 2, [voir le cours](02-les-reseaux-sociaux/cours.md#lex-graphe02))*

### H

**HTML** — Langage de balisage qui décrit le contenu et la structure d’une page web. *(ch. 4, [voir le cours](04-le-web/cours.md#lex-html04))*

**HTTP, HTTPS** — Protocole du dialogue entre client et serveur ; HTTPS en est la version sécurisée (données chiffrées). *(ch. 4, [voir le cours](04-le-web/cours.md#lex-http04))*

**Hypertexte, hyperlien** — Texte augmenté de renvois cliquables (les hyperliens) vers d’autres documents. *(ch. 4, [voir le cours](04-le-web/cours.md#lex-hypertexte04))*

### I

**Identité numérique** — Ensemble des informations qui vous représentent en ligne, y compris les traces laissées sans y penser. *(ch. 2, [voir le cours](02-les-reseaux-sociaux/cours.md#lex-identite02))*

**Indentation** — Décalage des lignes qui indique, en Python, quelles instructions forment un bloc. *(ch. 1, [voir le cours](01-les-bases-de-la-programmation-python/cours.md#lex-indentation01))*

**Instruction conditionnelle** — Bloc d’instructions exécuté seulement si une condition est vraie (`if`, `elif`, `else`). *(ch. 1, [voir le cours](01-les-bases-de-la-programmation-python/cours.md#lex-condition01))*

**Interface homme-machine (IHM)** — Moyens de commander une machine et d’en recevoir un retour (écran, boutons, voix…). *(ch. 8, [voir le cours](08-informatique-embarquee-et-objets-connect/cours.md#lex-ihm08))*

**Internet** — Réseau physique mondial de machines qui échangent des données grâce au protocole IP. *(ch. 4, [voir le cours](04-le-web/cours.md#lex-internet04))*

### L

**Langage de programmation** — Langage qui permet d’écrire des programmes compréhensibles par la machine après traduction ; de bas niveau (proche de la machine) ou de haut niveau (proche du langage humain), comme Python. *(ch. 1, [voir le cours](01-les-bases-de-la-programmation-python/cours.md#lex-langage01))*

**Langage machine** — Seul langage que le processeur comprend vraiment : une suite de 0 et de 1. *(ch. 1, [voir le cours](01-les-bases-de-la-programmation-python/cours.md#lex-langagemachine01))*

**Latitude, longitude** — Angles qui repèrent un point : Nord–Sud par rapport à l’équateur, Est–Ouest par rapport au méridien de Greenwich. *(ch. 7, [voir le cours](07-localisation-cartographie-et-mobilite/cours.md#lex-latitude07))*

### M

**Métadonnée** — Donnée qui décrit une autre donnée (date, taille, appareil, position d’une photo…). *(ch. 5, [voir le cours](05-les-donnees-structurees-et-leur-traiteme/cours.md#lex-metadonnee05))*

**Métadonnées EXIF** — Données rangées dans un fichier photo : date, appareil, réglages et souvent la position GPS. *(ch. 3, [voir le cours](03-la-photographie-numerique/cours.md#lex-exif03))*

**Microcontrôleur** — Petit processeur d’un système embarqué. *(ch. 8, [voir le cours](08-informatique-embarquee-et-objets-connect/cours.md#lex-microcontroleur08))*

**Module** — Boîte à outils de fonctions supplémentaires que l’on importe (`math`, `turtle`…). *(ch. 1, [voir le cours](01-les-bases-de-la-programmation-python/cours.md#lex-module01))*

**Moteur de recherche** — Service qui explore le Web avec des robots, range les pages dans un index et classe les réponses à une requête. *(ch. 4, [voir le cours](04-le-web/cours.md#lex-moteur04))*

### N

**Navigateur** — Logiciel client qui demande les pages web et les affiche (Firefox, Chrome…). *(ch. 4, [voir le cours](04-le-web/cours.md#lex-navigateur04))*

**Nuage (*cloud*)** — Données stockées sur des serveurs distants, accessibles par Internet. *(ch. 5, [voir le cours](05-les-donnees-structurees-et-leur-traiteme/cours.md#lex-nuage05))*

### O

**Objet connecté, IoT** — Objet à capteurs ou actionneurs qui échange des données par un réseau ; leur ensemble forme l’Internet des objets (IoT). *(ch. 8, [voir le cours](08-informatique-embarquee-et-objets-connect/cours.md#lex-objetconnecte08))*

**Open data** — Données publiques librement téléchargeables et réutilisables (data.gouv.fr, portail de Monaco…). *(ch. 5, [voir le cours](05-les-donnees-structurees-et-leur-traiteme/cours.md#lex-opendata05))*

### P

**Pair-à-pair (P2P)** — Réseau sans serveur central, où chaque machine est à la fois émetteur et récepteur. *(ch. 6, [voir le cours](06-internet/cours.md#lex-p2p06))*

**Paquet** — Petit morceau de données qui voyage sur Internet avec l’adresse de l’expéditeur, celle du destinataire et un numéro. *(ch. 6, [voir le cours](06-internet/cours.md#lex-paquet06))*

**Paramètre** — Valeur d’entrée d’une fonction, placée entre parenthèses après son nom. *(ch. 1, [voir le cours](01-les-bases-de-la-programmation-python/cours.md#lex-parametre01))*

**Petit monde** — Idée qu’une courte chaîne de connaissances relie deux inconnus (« six degrés de séparation », expérience de Milgram, 1967). *(ch. 2, [voir le cours](02-les-reseaux-sociaux/cours.md#lex-petitmonde02))*

**Photosite** — Petite cellule d’un capteur qui mesure la quantité de lumière reçue. *(ch. 3, [voir le cours](03-la-photographie-numerique/cours.md#lex-photosite03))*

**Pixel** — Point coloré de l’image numérique (*picture element*). *(ch. 3, [voir le cours](03-la-photographie-numerique/cours.md#lex-pixel03))*

**Poids (d’une image)** — Taille du fichier : environ largeur $\times$ hauteur $\times$ 3 octets avant compression. *(ch. 3, [voir le cours](03-la-photographie-numerique/cours.md#lex-poids03))*

**Polygone régulier (tortue)** — Pour tracer un polygone régulier à $n$ côtés, la tortue tourne de $360/n$ degrés à chaque sommet. *(compl., [voir le cours](dessiner-avec-la-tortue/cours.md#lex-polygoneT))*

**Programme** — Suite d’instructions données à un ordinateur pour qu’il effectue une tâche. *(ch. 1, [voir le cours](01-les-bases-de-la-programmation-python/cours.md#lex-programme01))*

### R

**Réseau social** — Service en ligne qui permet de se créer un profil, de se relier à d’autres personnes et de partager des contenus. *(ch. 2, [voir le cours](02-les-reseaux-sociaux/cours.md#lex-reseausocial02))*

**Résolution** — Nombre de pixels par unité de longueur, souvent en ppp (pixels par pouce). *(ch. 3, [voir le cours](03-la-photographie-numerique/cours.md#lex-resolution03))*

**RGPD** — Règlement européen qui protège les données personnelles (consentement, droit d’accès, droit à l’oubli) ; à Monaco, loi n° 1.565 (2024). *(ch. 2, [voir le cours](02-les-reseaux-sociaux/cours.md#lex-rgpd02))*

**Rosace** — Figure obtenue en répétant un même motif et en tournant d’un petit angle à chaque fois. *(compl., [voir le cours](dessiner-avec-la-tortue/cours.md#lex-rosaceT))*

**Routeur, routage** — Le routeur aiguille chaque paquet vers la prochaine étape ; le routage est ce cheminement de proche en proche. *(ch. 6, [voir le cours](06-internet/cours.md#lex-routeur06))*

**RVB (synthèse additive)** — Codage d’une couleur par trois nombres de 0 à 255 (Rouge, Vert, Bleu) ; mélanger ces trois lumières donne toutes les couleurs. *(ch. 3, [voir le cours](03-la-photographie-numerique/cours.md#lex-rvb03))*

### S

**Système embarqué** — Ordinateur intégré dans un objet, dédié à une tâche précise. *(ch. 8, [voir le cours](08-informatique-embarquee-et-objets-connect/cours.md#lex-embarque08))*

### T

**Table de données** — Données rangées en lignes (les enregistrements) et en colonnes (les descripteurs). *(ch. 5, [voir le cours](05-les-donnees-structurees-et-leur-traiteme/cours.md#lex-table05))*

**Tableur** — Logiciel pour trier, filtrer, calculer et représenter les données d’une table. *(ch. 5, [voir le cours](05-les-donnees-structurees-et-leur-traiteme/cours.md#lex-tableur05))*

**TCP/IP** — Protocoles d’Internet : IP adresse et achemine les paquets, TCP vérifie qu’ils arrivent tous et les remet dans l’ordre. *(ch. 6, [voir le cours](06-internet/cours.md#lex-tcpip06))*

**Trame NMEA** — Ligne de texte envoyée par un récepteur GPS : heure, latitude, longitude, nombre de satellites…*(ch. 7, [voir le cours](07-localisation-cartographie-et-mobilite/cours.md#lex-nmea07))*

**Trilatération** — Calcul d’une position en croisant les distances à plusieurs satellites. *(ch. 7, [voir le cours](07-localisation-cartographie-et-mobilite/cours.md#lex-trilateration07))*

**Type** — Nature d’une valeur : entier (`int`), nombre à virgule (`float`), chaîne de caractères (`str`), booléen (`bool`). *(ch. 1, [voir le cours](01-les-bases-de-la-programmation-python/cours.md#lex-type01))*

### U

**URL** — Adresse d’une page web. *(ch. 4, [voir le cours](04-le-web/cours.md#lex-url04))*

### V

**Variable** — Donnée rangée dans la mémoire, repérée par un nom et qui contient une valeur, laquelle peut changer. *(ch. 1, [voir le cours](01-les-bases-de-la-programmation-python/cours.md#lex-variable01))*

### W

**Web** — Service d’Internet : des pages reliées par des hyperliens, consultées avec un navigateur. *(ch. 4, [voir le cours](04-le-web/cours.md#lex-web04))*
