# Épreuve pratique : sujets d'entraînement

Ces sujets d’entraînement reprennent le format de l’épreuve pratique du baccalauréat (durée 1 heure, fichier Python à compléter, appels professeur), mais ne font pas partie de la banque nationale. Ils approfondissent des notions que celle-ci travaille peu : arbres, graphes, cryptographie, recherche textuelle, programmation dynamique. Ils sont numérotés à partir de 24 car ils font suite à une première série de 23 sujets d’entraînement, qui ne figure pas dans ce livre. Les fichiers fournis (codes de départ et données) sont à télécharger : le lien (et le QR code) vers le dossier du sujet et vers l’archive .zip est indiqué en tête de chaque sujet (aucun compte n’est nécessaire). Le corrigé se déplie sous chaque exercice.
